Architecture

The Hybrid Safety Stack

Two independent systems that cover each other's blind spots.

Layer 1The Clinical Doctor
Data Source: UniTox.csv — FDA drug labels with physician-documented organ toxicity (Heart, Liver, Kidney, Lungs, Fertility).
Method: Pandas DataFrame lookup matching the drug name against verified clinical records — returns rating + doctor reasoning.
Strength: 100% authoritative for known drugs. Real human outcomes, not simulated results.
Weakness: Cannot assess novel compounds — only works for drugs already present in the database.
Layer 2The AI Chemist
Data Source: Tox21 dataset — compounds tested against 12 nuclear receptor and stress-response assays in vitro.
Method: RDKit generates 2048-bit Morgan fingerprints. A Random Forest model returns probability scores per assay target.
Strength: Can evaluate any chemical structure — including brand-new compounds with no clinical history.
Weakness: Probabilistic, not certain. In-vitro results don't always translate to in-vivo human responses.

System Flow

How DeepTox Works

A step-by-step walkthrough — from the moment you type a drug name to the final toxicity dashboard.

01
User Input
The user provides a common drug name (e.g. "Aspirin") or a raw SMILES code. Both are accepted. A toggle on the frontend tells the backend which format to expect.
# Two accepted formats
name  = "Aspirin"
# OR
smiles = "CC(=O)Oc1ccccc1C(=O)O"
02
SMILES Resolution via PubChem
If a name is typed, PubChemPy calls the PubChem REST API to retrieve the canonical isomeric SMILES. If SMILES was directly provided, this step is skipped entirely.
import pubchempy as pcp
results = pcp.get_compounds(name, 'name')
smiles = results[0].isomeric_smiles
03
Clinical Database Scan (UniTox)
Pandas searches UniTox.csv for the drug name. If found, it returns physician-verified toxicity ratings and clinical reasoning for Heart, Liver, Kidney, Lungs, and Fertility.
df = pd.read_csv('UniTox.csv')
match = df[df['Clean_Name'] == name.lower()]
# Binary Rating + Reasoning per organ
04
Molecular Fingerprinting (RDKit)
RDKit parses the SMILES string into a molecule object, then generates a 2048-bit Morgan fingerprint (radius=2) — a dense binary vector encoding each atom's chemical neighborhood.
from rdkit.Chem import rdFingerprintGenerator
mfpgen = rdFingerprintGenerator.GetMorganGenerator(
  radius=2, fpSize=2048)
fp = mfpgen.GetFingerprintAsNumPy(mol)
05
Random Forest Prediction (Tox21)
The fingerprint is passed to the trained Random Forest model. It returns probability scores for 12 assay targets — nuclear receptors (NR) and stress response pathways (SR).
model = joblib.load('tox21_model.joblib')
probs = model.predict_proba(fp)
# Returns list of [p_safe, p_toxic] per assay
06
Unified JSON Response (Flask)
Flask compiles both layers into a single JSON response — clinical organ ratings with reasoning, AI risk percentages per assay, and an overall risk level — sent to the frontend.
return jsonify({
  "clinical": {"found": true, "organs": [...]},
  "ai_risks": [{"effect":..., "risk_pct":...}],
  "overall_risk": "moderate"
})

The Project

What is DeepTox?

DeepTox is a research-grade hybrid toxicity prediction system that addresses a fundamental limitation: neither clinical databases nor AI models alone can give you the full picture.

Clinical databases know what's already dangerous — but they're blind to novel compounds. AI models can predict new risks — but lack the authority of verified human data. DeepTox runs both simultaneously and presents their findings side by side.

The system is built entirely in Python, with scikit-learn, RDKit, Pandas, PubChemPy, and Flask forming the core stack. The frontend is a custom dark-themed single-page application with a glassmorphic medical dashboard aesthetic.

Design Philosophy

Why It Was Built This Way

🔗
Bridge the Gap
Most tools rely on a single data source. DeepTox deliberately combines verified human outcomes with predictive AI to cover what each method misses independently.
🎯
Honest Uncertainty
The system clearly labels "verified by doctors" vs "predicted by AI" — because the confidence level and nature of evidence from each source is fundamentally different.
⚗️
Novel Compound Ready
For chemicals with no clinical history, the AI layer provides a meaningful first-pass risk estimate based on structural similarity to thousands of tested compounds.
FAQ

Common Questions

Can DeepTox be used for real medical decisions? ▾
No. DeepTox is a research prototype. It is not a validated clinical tool and must never be used to make medical decisions for any individual. Always consult qualified medical professionals.
What does "not found in UniTox" mean? ▾
It means the drug is not present in the UniTox dataset being used — not that it is safe. In this case, DeepTox relies entirely on the Layer 2 AI prediction from the Tox21 model.
What are the 12 Tox21 assay targets? ▾
The 12 targets cover nuclear receptors (NR-AR, NR-AhR, NR-Aromatase, NR-ER, NR-ER-LBD, NR-PPAR-gamma) and stress response pathways (SR-ARE, SR-ATAD5, SR-HSE, SR-MMP, SR-p53, SR-Mitochondrial). Each represents a biological pathway that toxic chemicals can disrupt.
Why does the frontend show demo data sometimes? ▾
If the Flask backend server isn't running at http://127.0.0.1:5000, the frontend falls back to demo data to remain usable for presentation purposes. Start the backend with python app.py for live predictions.

PubChem is the world's largest collection of freely accessible chemical information. DeepTox uses the PubChem REST API (via PubChemPy) to resolve common drug names into canonical SMILES structures at runtime.
